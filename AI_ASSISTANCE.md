## How AI Assisted During Development

AI was used as a development assistant throughout the implementation of StampQuest rather than as a replacement for manual coding.

AI helped with the following tasks:

* Creating the initial React project structure.
* Generating reusable React components.
* Designing the travel passport layout.
* Building the Add Visit form.
* Creating the Stamp Card component.
* Implementing Local Storage for persistent data.
* Suggesting responsive CSS layouts.
* Generating the achievements feature.
* Recommending React Hooks and component organisation.
* Reviewing the project for possible improvements.

Each AI-generated response was carefully reviewed before implementation. Any unnecessary code, duplicated logic, or naming inconsistencies were corrected manually to improve readability, maintainability, and overall code quality.

The final application reflects a combination of AI-assisted development and manual engineering decisions, ensuring the project meets React best practices while remaining clean, responsive, and user-friendly.
